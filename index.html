Двуязычный сборник RFC по SIP

186 документов SIP-стека на русском: английский оригинал слева, перевод справа, на одной странице. С поиском по содержимому и PDF каждой книги.

Открыть сборник

Перевод выполнен с помощью ИИ (DSF 4.1). Возможны неточности — сверяйтесь с оригиналом. Оригиналы документов: rfc-editor.org.

Что внутри

  • RFC 3261 (SIP), 3262, 3265, 3550 (RTP), 4566 (SDP), 5389 (STUN), 5766 (TURN), 8445 (ICE), 3711 (SRTP) и другие;
  • IMS-профили: P-заголовки, конференции, KPML, SIP MIB;
  • кодеки: iLBC, AMR/AMR-WB, G.729.1, G.719, MPEG-4 Audio, MP3;
  • каждая книга — две колонки: оригинал и перевод, без искажений английского текста;
  • оглавление с поиском по содержимому всех книг;
  • PDF в ландшафтном формате A4.

Инструменты

Аудитор вёрстки, которым проверялся сборник, открыт отдельно: репозиторий на GitHub. 39 автоматических проверок, 34 детектора, описание 45 классов дефектов.

Зачем это нужно

Полных переводов RFC 3261 на русский в открытом доступе нет: существуют французский, китайский и японский переводы, а русский SIP-стек оставался непереведённым. Этот сборник закрывает пробел — с параллельным оригиналом, чтобы спорное место можно было сверить, не открывая второй файл.
